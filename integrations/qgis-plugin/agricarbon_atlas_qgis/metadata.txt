description=Send a field polygon and a tree count to your AgriCarbon Atlas API and see scenario carbon estimates (estimates, not credits).
about=Bridges QGIS and the open-source AgriCarbon Atlas API. Select a field polygon, count the tree crowns detected in a segmentation layer (for example the output of an AI segmentation plugin), then request the estimated annual carbon removal (low, central and high), indicative carbon value scenarios and a programme screening.
    These are scenario estimates, not issued carbon credits: every result is shown with certified: false. Environmental benefit, indicative carbon value and other farm income are always shown separately and are never added together.
    The field polygon is sent only to the API address you configure. Experimental release. This plugin is GPL-2.0-or-later; the AgriCarbon Atlas API itself is Apache-2.0.

    - First experimental release.
    - Send the selected field polygon to your AgriCarbon Atlas API and analyse it.
    - Count tree crowns from a segmentation layer (centroid inside the field, optional confidence filter) and record a tree inventory.
    - Carbon estimate with separate environmental benefit, indicative value scenarios and other farm income, plus programme screening and evidence readiness.
    - Run the AI agent team and read its transcript.
