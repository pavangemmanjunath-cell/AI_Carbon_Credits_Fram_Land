# Use cases

- **Farmer or landowner:** mark the land, add trees, see a range for annual carbon removal and a checklist of missing
  evidence for programmes in India, the US or the EU.
- **Advisor or extension worker:** screen programmes, check tree-age rules (heritage trees, tree pensions, credit
  eligibility), produce a report.
- **Researcher:** reproduce the benchmarks, swap in new parameters with sources, add a region or a model.
- **Student:** read the small agent framework in `packages/agent-framework` and run `make agents-demo`.
- **GIS user:** call the API from the QGIS plugin in `integrations/qgis-plugin`.
